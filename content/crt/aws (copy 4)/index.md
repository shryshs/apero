## About

The Certified Kubernetes Administrator (CKA) validates the
skills required to administer Kubernetes clusters in production.

## Skills Covered

- Cluster installation
- Networking
- RBAC
- Storage
- Security
- Troubleshooting

## Experience

I prepared by deploying clusters using kubeadm,
managing RBAC, configuring ingress, and troubleshooting
production-like scenarios.

This certification complements my Kubernetes projects,
including deploying containerized machine learning
applications on Kubernetes.
